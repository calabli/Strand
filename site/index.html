日志和历史

log --graph

大仓库也能秒开：日志结构先读出来，说明和作者按页取。图谱在后台线程算，滚动不卡。

图谱和过滤

按分支、作者、日期、路径过滤，搜索支持正则和区分大小写，也能在改动内容里搜。单击分支只看它。

逐行追溯和文件历史

每行左边写着谁在哪天改的，越新底色越深；右键一行“追溯改动之前的版本”，一路往前追。修改链跟着改名走，任选两个版本对比。

二分查找

在提交上标好、坏，日志上方的提示条显示正在测哪个、大约还要几步，找到后直接定位第一个坏提交。

操作记录（reflog）

重置、变基、删分支丢下的提交标成“不在日志里”，从那一行新建分支就找回来了。

差异

合并视图或左右对比，左右各自横向滚动；忽略空白、语法高亮、代码位置面包屑，工作区文件可以直接在差异里改。

图片对比

png、jpg、gif、webp 显示两边的图、尺寸和大小，并排、滑动或叠加着看。合并冲突里的图片也能先看再选。

文件标签页

一个文件一个标签，可以固定。⌘W 关掉、⇧⌘T 重新打开、⌘E 列出最近的文件，右键关闭其他、左侧、右侧或全部。

项目文件和内容搜索

目录树里点开任何文件，用 git grep 在工作区或某个版本里搜内容，结果按文件分组，点一处跳过去。

控制台

Strand 执行的每一条 git 命令、用时和输出都列在控制台里，凭据自动打码，出了问题一眼看到是哪一步。

提交，细到每一行

commit --only

勾选文件或单独几行，部分勾选在临时索引里搭好再提交，没勾的行原样留在工作区。钩子、签名和换行符转换照常运行。

变更列表

把改动分成几组分开提交。新改动进“活动”列表，文件可以在列表之间移动。

作者和共同作者

这一次换个作者提交，或者加共同作者，写成说明末尾的 Co-authored-by 行。

说明历史和模板

翻出自己在这个仓库写过的说明；读取 commit.template，模板原样没改不让提交。

提交前检查

提交前先格式化、再跑检查命令，问题按文件和行号列出来，可以点进去看，也可以仍然提交。

暂存架和贮藏

把一部分改动搁起来，可以连同未跟踪的新文件一起；之后只取回其中几个文件，取回有冲突时逐个处理。

整理提交

上移、下移、并入、丢弃、改说明，实时显示“N 个提交整理后变成 M 个”；Fixup 并入更早的提交，整个是一步撤销。

做错了，按 ⌘Z

oplog

Strand 给每个写操作记一笔，日志底部的时间线列出最近几步。点一步，就回到这一步之前。下面这个可以点着试。

操作时间线（新的在上）

点一步试试。

  • 不只是提交。重置、变基、整理提交、删分支、丢弃改动、拣选、搁置都能撤销，也能重做。
  • 越过已推送的步骤会先问。撤销后要强制推送才能让远程一致，确认了才做。
  • 别处改过会标出来。在命令行里切了分支或提交了，时间线上受影响的步骤置灰，并说明原因。
  • Git 记的也能看。时间线管不到的，操作记录（reflog）窗口里还能找到。

冲突和分支

merge / rebase

冲突解决是三栏合并窗口：你的、结果、对方的。每个修改块单独标记，结果实时预览，最后一个文件解决后自动完成。

三栏合并

行内差异加深、位置标尺、上下处跳转、撤销重做；变基冲突按提交逐个解决，可以跳过某个提交。

拖拽合并或变基

把分支拖到另一个分支上松开，选合并还是变基。已经在它之上、有合并提交时预先置灰并说原因。

推送到这里为止

只推送到某个提交；需要强制推送的分支在分支树里标出来。多个远程时可以选推到哪个。

工作目录

用 git worktree 在新文件夹里检出分支，在 Strand 里直接切过去。

补丁

为提交或勾选的文件创建补丁；把 .patch 拖进窗口应用，format-patch 的补丁可以直接生成提交。

签名和标签

带说明的标签、签名标签；提交详情里显示签名是否有效，GPG 和 SSH 都行。

子模块

分支树里列出子模块和状态：没初始化、检出的提交不同、里面有改动。一键更新到记录的提交，或者在 Strand 里打开它。

Git LFS

LFS 文件的差异、全文和图片对比显示真实内容，而不是指针；还没下载的文件提示一下，点一下就 git lfs pull。

自动更新

启动时看看 GitHub 上有没有新版本，有的话在角落提示，下载、核对签名、安装、重启一气呵成。可以关掉。

为什么快，又为什么稳

Rust · Tauri

读用库，写交给系统 Git。所以读得快，写的时候和你在终端里敲的一样：钩子、签名、换行符转换都不变。

读日志

gix

纯 Rust 读提交图，有 commit-graph 文件时直接用；没有就在后台生成，下次打开更快。

状态和差异

git2

先让系统 git 找出变了的文件，再只对这几个算行数和改名，大工作区也跟得上。

提交、合并、网络

系统 git

所有写操作和抓取、推送都调用你装的 git，凭据弹窗由 Strand 接住，控制台里能看到每一条命令。

下载

v0.1.5

Strand 调用你电脑上的 Git，所以先装好 Git 2.30 以上。所有版本和更新说明在 GitHub Releases。

macOS · Apple 芯片
下载 dmg（6.4 MB）

没有经过苹果公证：第一次打开时在“应用程序”里右键 Strand 选“打开”，或者到“系统设置 › 隐私与安全性”里允许。提示“已损坏”时在终端运行 xattr -dr com.apple.quarantine /Applications/Strand.app。

Windows · x64
下载安装程序（5.1 MB）
MSI 安装包（7.2 MB） 免安装版 exe（15.7 MB）

没有签名，SmartScreen 可能会让你确认一次。免安装版需要 WebView2，Windows 10 和 11 一般已经自带。

从源码构建

pnpm tauri build

需要 Rust 1.88 以上、Node.js 20 以上、pnpm 和 Git 2.30 以上。Windows 还需要 WebView2 和 Visual Studio 生成工具。

pnpm install
pnpm tauri dev
pnpm tauri build --bundles app,dmg

在 Apple 芯片的 Mac 上打包约 3 分钟，产物在 target/release/bundle/。现在是临时签名，发给别人时，对方第一次打开要在访达里右键选“打开”。
